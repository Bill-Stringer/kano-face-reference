Kano Reference

In each original photo, the person on the left is the reference subject. The focused crops below are provided to make the intended subject clearer.

Critical reference requirements

  • The intended subject is always the left person in each original photo.
  • Use these images as identity and appearance references for Kano.
  • Keep the overall school-uniform impression consistent when relevant.

Sock reference requirement

  • The socks must be reproduced exactly as shown in the reference images.
  • Use the same sock type, the same black colour, and the same short ankle length.
  • The length must stay short, ankle-length, and close-fitting around the ankle.
  • Do not change them into crew socks, long socks, loose socks, folded socks, tights, stockings, bare feet, or any other sock style.
  • The sock type and sock length are essential reference elements and should be matched as faithfully as possible.

靴下に関する絶対指定（日本語）

  • 靴下は参考画像と同じ種類・同じ黒色・同じ短めのくるぶし丈で再現してください。
  • 丈感は、短い・くるぶし丈・足首に比較的フィットした見え方を維持してください。
  • クルー丈、長い靴下、だぼついた靴下、折り返しソックス、タイツ、ストッキング、素足にはしないでください。
  • 靴下の種類と長さは、キャラクター参照上の重要要素です。可能な限り忠実に合わせてください。
